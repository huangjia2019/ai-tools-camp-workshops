## 使用说明

- 交易所通知是练习文本，据公开报道整理；规则摘录取自交易所公开文件。正式内容以交易所官网现行文本为准，这些材料不能用于实际业务。
- 小工具里的结算价、账户和持仓都是教学数值，不是真实行情。
- 只用这里的练习材料，不要把公司代码、账号和业务数据放进 AI 工具。
- 每场工作坊另有纸质角色卡，课上发放，这里没有。
