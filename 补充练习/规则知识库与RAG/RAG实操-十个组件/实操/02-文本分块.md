# 实操二　文本分块：按条款切，一条规则一块，每块带上文件标题

只改 `rag/chunk.py`。

## 现象

```
python check.py 02 --看
```

基础版每 80 个字切一块，不管句子和条款在哪里结束。交易限额规定的第一条和第二条切进同一块，第二条又被切成两半；会员问答里，问句和答句分在两块。

## 要做的事

1. 按空行分段，一段一块：一条规则、一个问答、表格改写后的一行，各成一块。
2. 一段超过 160 个字时，在句号或分号处再切，不在句子中间断开。
3. 每块前面加上文件标题，用“｜”隔开，例如“练习金属期货交易限额规定｜第一条　……”。块离开原文以后，仍然看得出出自哪份文件。
4. 开头以“>”开头的说明行不进块。

## 操作要求

Qoder CN：先在智能问答模式分析目标文件与失败用例，确认后切到智能体模式修改。

TRAE：引用目标文件与用例，先分析，再按确认的范围修改。两款工具都把下面这段提示词交给 AI，改完在项目终端运行“检查”里的命令。

```
只改 rag/chunk.py。改成按空行分段，每段一块；超过 160 个字的段在句号或分号处再切；每块前面加上文件标题，用“｜”隔开；以“>”开头的说明行跳过。块的字段（id、doc、text、meta）保持不变。改完运行 python check.py 02。
```

## 检查

```
python check.py 02
python eval.py --save 实操02
python eval.py --compare 基线 实操02
```

`check.py 02` 查这几项，逐项检查并记录未通过的原因：

- 交易限额规定：第一条完整地在一块里，不和第二条混在一起
- 会员问答：一问一答在同一块里
- 第102号：第三条整句在一块里
- 每一块都带着文件标题
- 没有超过 300 字的大块
