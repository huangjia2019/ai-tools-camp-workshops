# 实操八　响应生成：会拒答，按问题挑句子，更正只用于它针对的那一项

只改 `rag/generate.py`。

## 现象

```
python check.py 08 --看
```

基础版按字面重合挑一句照抄：问“明天会涨停吗”也照样作答；问“平今是什么意思”，挑中的是问句本身；更正过的比例照抄原通知的 9%，只引一份文件。

## 要做的事

1. 拒答：问行情走势（会不会涨停、跌停）和账户情况的，结论写“资料中没有依据，不能回答”，不写依据；问到的事项在交上来的块里一句都没提到（例如交割手续费），也拒答。
2. 按问题挑句子：问“多少”优先挑带数值和单位的句子；问“什么意思”挑定义句；问句（“问：”开头、问号结尾）不用。
3. 更正：结论所在的文件被更正过时，先看更正通知改的是原通知哪一条、哪一项。结论句讲的正是被更正的那一项（例如都是套期保值持仓的保证金比例），结论才用更正通知那一句，依据同时引原通知和更正通知；更正没涉及的条款照原通知，也不引更正通知。第 103 号只更正了第 102 号第三条的套期保值比例，问一般持仓时它不适用。
4. 回答格式不变：第一行“结论：”，后面每份文件一行“依据：〔编号〕原文”。

## 操作要求

Qoder CN：先在智能问答模式分析目标文件与失败用例，确认后切到智能体模式修改。

TRAE：引用目标文件与用例，先分析，再按确认的范围修改。两款工具都把下面这段提示词交给 AI，改完在项目终端运行“检查”里的命令。

```
只改 rag/generate.py 里的 answer(req, hits)。问行情走势、账户情况的直接拒答；问题里的关键名词（手续费、交割、保证金这类）在块里一句都没出现时拒答；拒答时只写结论一行。挑结论句子时：问“多少”的优先带数值和单位的句子，问“什么意思”的优先“指……”的定义句，不用问句。结论所在文件的元数据有“被更正”时，只有更正通知的句子也讲到结论句里的事项（一般持仓、套期保值这类词都对得上），才改用更正通知的句子，依据同时引用两份文件；对不上的照原通知，不引更正通知。回答格式不变。改完运行 python check.py 08。
```

## 检查

```
python check.py 08
python eval.py --save 实操08
python eval.py --compare 基线 实操08
```

`check.py 08` 查这几项，逐项检查并记录未通过的原因：

- 问明天会不会涨停：拒答，不写依据
- 问交割手续费，资料里没有：拒答
- 更正过的比例：结论用 8%，依据同时引第102号和第103号
- 问收费标准：挑带数值的那一句（8000 元/月）
- 问什么意思：结论用答句，不用问句
- 问一般持仓：第103号只更正套期保值，结论用 9%，不引第103号
