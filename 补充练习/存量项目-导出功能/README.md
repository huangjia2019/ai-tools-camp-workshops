# 存量项目：报销记录导出

| 文件 | 内容 |
| --- | --- |
| app.py | 运行入口：显示页面查询和导出结果 |
| query.py | 练习数据和已有的查询 |
| reports.py | 新增的 CSV 导出 |
| test_reports.py | 测试 |

```
python3 app.py
python3 -m unittest -v
```

Windows 上用 python。

## 给 AI 的要求

```
先不要修改代码。找到页面查询和 CSV 导出的调用路径，说明两者的数据范围为什么不同，给出文件名和函数名。提出最小修改方案，确认后只修改 reports.py。保留原有查询行为和测试期望值。修改后运行全部测试，说明还有哪些情况没有检查。
```


## 工具操作

Qoder CN：先用智能问答模式阅读需求与文件，确认方案后切到智能体模式修改。TRAE：先分析需求与文件，确认后再允许修改。保留初始文件，核对代码差异并执行材料中的检查。
