# 模块一

按编号做，每次用工具打开一个文件夹。

| 文件夹 | 做什么 |
| --- | --- |
| [01-动手一-涨跌停计算器](01-动手一-涨跌停计算器/) | 文件夹里只有一份 README（提示词和试算数据）。让工具从空文件夹生成一个 HTML 计算器，再用 78410、9%、10 核对涨停价和跌停价 |
| [02-读已有项目-期货前置检查](02-读已有项目-期货前置检查/) | 一个已有的期货下单前检查小项目。让工具说清 check 的输入、调用顺序和返回值，每一条回到源码核对 |
| [03-工作坊一-通知来了](03-工作坊一-通知来了/) | 交易所发来参数调整通知，按需求单和资料包把初始版程序改成新版，用三道题核对结果 |
