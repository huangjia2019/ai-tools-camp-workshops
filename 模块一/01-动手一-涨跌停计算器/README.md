# 动手一：涨跌停计算器

用 Qoder CN、TRAE 或 CodeBuddy 打开本文件夹（菜单“文件 → 打开文件夹”）。文件夹里只有这份说明：把下面的提示词交给工具，生成一个 HTML 计算器，再用试算数据核对。

## 提示词

```
做一个网页小工具：涨跌停价计算器。
输入：上一交易日结算价、涨跌停板幅度（%）、最小变动价位。
输出：涨停价、跌停价，以及计算过程。
规则：涨停价 = 结算价 ×（1 + 幅度），跌停价 = 结算价 ×（1 − 幅度）；
结果必须是最小变动价位的整数倍。
价格计算不能用浮点数。做成一个单独的 HTML 文件，双击就能打开。
```

试算：结算价 78410，涨跌停板幅度 9%，最小变动价位 10。


## 工具操作

Qoder CN：先用智能问答模式确认输入、计算公式和取整规则，再切换到智能体模式生成 HTML。TRAE：在输入框输入 `/plan` 选择 Plan 命令，贴需求时要求先确认取整规则、再生成计算器；TRAE 写出实施计划（在 `.trae/documents/` 下），确认“执行此方案”后再生成 HTML。生成后用上面的试算数据核对计算过程和取整方向。
