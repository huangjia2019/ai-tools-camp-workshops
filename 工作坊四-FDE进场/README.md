# 工作坊四：FDE 进场 · 一页纸

## 任务

为“参数变更单起草智能体”写一页项目说明，按六个要素写，每条注明提供人；只有一个人提供的标“单一来源”；成员说法不一致的，两种都写，进待确认。另写两段：这个智能体不做什么，哪一步必须停下来等人确认。

成员先把事实填进模板，再请 WorkBuddy 整理。三分钟没返回，就在模板上接着人工写。第三轮逐条核对时，谁都可以问“还有谁能印证”。

## 一页纸模板

```
对象与身份：
关系：

规则：
动作：
证据与结果：
不做什么：
需要暂停确认的条件：
待确认：
```

## 给 WorkBuddy 的提示词

```
只依据下面的成员事实，直接整理一页纯文本草稿，不生成文件，不查外部资料。

帮我们起草一页纸：一个“参数变更单起草智能体”的项目说明。
背景：交易所每发一份参数调整通知，这个智能体就起草一张参数变更单，交给结算部门复核。
按六个要素写，每个要素两三行：
1. 对象与身份　2. 关系　3. 状态与时间　4. 规则　5. 动作　6. 证据与结果
另写两段：这个智能体不做什么；哪一步必须停下来等人确认。
每一条注明提供人；只有一个人提供的，标“单一来源”。
成员说法不一致的，两种说法都列出来，写进“待确认”，不要替我们选。
通知原文照抄，不改写；同一个词在全文里只表示一个意思。

【成员提供的事实】
1. ……（提供人：……）
```
