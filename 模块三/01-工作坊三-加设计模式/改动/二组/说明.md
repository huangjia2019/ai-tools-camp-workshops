# 二组的改动

问题方向：节假日与日历。先看第 101 号通知和 data/交易日历.csv。

## 文件

| Qoder CN | TRAE |
| --- | --- |
| `.qoder/skills/holiday-notice/SKILL.md` | `.trae/skills/holiday-notice/SKILL.md` |
| `.qoder/agents/red-team.md` | `.trae/agents/red-team.md` |

`准备.py` 会把用到的那一套放进 `加模式后/` 和 `加卡后/`，不用手动复制。以 `.` 开头的文件夹在访达里默认不显示，按 Command+Shift+. 可以看到。

## 让它生效

- Qoder CN：命令面板运行“开发人员: 重新加载窗口”，再新建会话。技能在会话里输入 `/` 能看到；子智能体在会话里输入 `/` 能看到。
- TRAE：技能在技能列表里能看到；子智能体要先在设置 → Beta 打开“启用 Subagents 目录”。

## 每一层都这样跑

1. 新会话发那一句请求。

2. 处理完没有自己调用挑错的子智能体时，再发下面这句。Qoder 先键入 `/red-team`、回车选中，再写后面的话；TRAE 写成“请 red-team 挑错；……”。第一层没有这个子智能体，这一步不发。

   ```
   挑错；对每一条写“采纳”或“不采纳”和理由，改完再请它看一轮，最多两轮，最后由我裁决。
   ```

## 每一遍看什么

第 101 号怎么处理：12 月 31 日当晚夜盘的出入怎么写，改没改交易日历；有没有逐日核对；调用记录里有没有加载技能；挑错找出的是不是真问题。

这一遍用了多长时间、调用记录里读了多少次文件，也记下来，第二层要写代价。
