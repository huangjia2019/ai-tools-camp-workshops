# 改动

六组各一份，第二层用。文件里不写模式名，要你们对照 [模式卡片/](../模式卡片/README.md) 认出它是哪个模式。

| 组 | 问题方向 | 文件 |
| --- | --- | --- |
| [一组](一组/说明.md) | 依据与更正 | rules/cite.md、agents/change-reviewer.md |
| [二组](二组/说明.md) | 节假日与日历 | skills/holiday-notice/SKILL.md、agents/red-team.md |
| [三组](三组/说明.md) | 哪些材料能作依据 | rules/context.md、rules/cite.md |
| [四组](四组/说明.md) | 历史记录 | rules/replay.md、rules/lessons.md |
| [五组](五组/说明.md) | 写入与审批 | hooks/approve_prod.py、hooks/scope.py、rules/approval.md，加上 Hook 配置 |
| [六组](六组/说明.md) | 中断与续跑 | rules/progress.md |

每组文件夹里有两套：`.qoder/` 给 Qoder CN，`.trae/` 给 TRAE，要求相同，写法按各自的工具。`.qoder/` 是 2026-11-09 在这份模板上实测过的配置；`.trae/` 照模式卡上 TRAE 的写法。用 准备.py 放进副本，不用手动复制。
