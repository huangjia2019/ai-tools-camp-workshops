# 工作坊三：加设计模式

| 文件 | 内容 |
| --- | --- |

开始前把 模板/ 复制两份，放在同一层，改名为 `加模式前` 和 `加模式后`：

1. 用 Qoder CN 或 TRAE 打开 `加模式前/`，什么都不加，新会话发下面的请求，跑一遍基础版。
2. 打开 `加模式后/`，照模式卡在里面建配置文件（`.qoder/` 或 `.trae/` 下），新会话发同一句请求，再跑一遍。
3. 两个文件夹的 `draft/` 变更单和 `prod/params.csv` 对照，就是加模式前后的差异。做乱了，删掉那一份，从 模板/ 重新复制。

通知处理请求：

```
按 AGENTS.md 处理 inbox 里的全部通知，把变更单写到 draft/。
```

Windows 上把命令里的 python3 换成 python。
