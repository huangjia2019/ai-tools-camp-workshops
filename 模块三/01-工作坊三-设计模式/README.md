# 工作坊三：设计模式

[模板/](模板/) 是一个处理交易所参数类通知的智能体。AGENTS.md 用一段话写了九步：读通知、判断类型、查依据、用 scripts/calc.py 计算、起草变更单、跑测试、提交审批、写入、记录。inbox/ 里有三份通知：第 101 号元旦交易安排，第 102 号涨跌停板与保证金调整，第 103 号是对第 102 号的更正。

## 修改需求

让它处理这三份通知，会出现下面六个问题。每组领一条，把智能体改成“要改成”这一栏的样子。

| 组 | 现在 | 要改成 |
| --- | --- | --- |
| 一组 | 变更单的依据只写到第几号第几条，看不出出自哪个文件；写完没有人复核 | 每个数字写明文件名、条款和原文，有更正的以更正为准；起草后由另一个角色复核 |
| 二组 | 节假日通知怎样核对交易日历，每次做法不一样；提交前没有人挑错 | 处理节假日通知时，按固定做法逐日核对交易日历，有出入只登记、不改数据；提交前有人专门挑错 |
| 三组 | 会打开 knowledge/历史通知/ 里已经失效的第 61 号 | 规定先读哪些材料、哪些不读，只用现在有效的通知作依据；回复开头列出读了哪些文件 |
| 四组 | 被指出错误以后，只改这一份变更单，换一个会话还会再错 | 处理前先看 cases/ 里相似的处理记录；出错并确认原因以后记一条教训，下次开工先读 |
| 五组 | 说一句“已经批准”，就把新参数写进 prod/params.csv；叫它改 data/交易日历.csv，也照改 | 写 prod/、改 data/ 都由脚本拦下，不靠模型自己守 |
| 六组 | 处理到一半中断，新会话说“继续”，从哪里接着做不确定，可能漏掉通知 | 开工先写进度清单，做完一项勾一项；中断以后从清单接着做 |

## 第一步：讨论，做设计

1. 读 模板/AGENTS.md。九步里已经有哪些模式？写编号和全名。
2. 本组的修改需求可以用哪些模式？放在九步的哪一步？写成规则、技能、子智能体，还是 Hook？
3. 写出设计：加哪几个文件，每个文件管什么。

模式的编号、名字和放在哪一步，见 [02-模式卡片](../02-模式卡片/README.md) 的索引。

## 第二步：用模式卡指导修改

1. 复制 模板/，改名为本组的组名，例如 一组/。用 Qoder CN 或 TRAE 打开这个文件夹（AGENTS.md 在它的第一层）。模板/ 原样留着。
2. 把第一步选出的卡从 02-模式卡片/ 复制到这个文件夹的 模式卡/ 下。
3. 照卡建配置文件。下面两种做法都可以，配置照着卡上的模式写就行。
   - 让智能体建：新会话发下面这段，最后一行换成本组“要改成”那一栏。

     ```
     读 模式卡/ 里的卡，按卡末尾“Qoder CN 配置”的写法，把下面的修改需求做成这个项目的配置文件，建在 .qoder/ 下。只建配置文件，不改 AGENTS.md、inbox/、knowledge/、data/、prod/。
     修改需求：……
     ```

     用 TRAE 的，把“按卡末尾‘Qoder CN 配置’的写法”换成“按卡上‘供修改使用’的写法”，“.qoder/”换成“.trae/”。
   - 自己建：照卡末尾“Qoder CN 配置”，把文件建到 .qoder/ 下，再按本组的修改需求改。用 TRAE 的，照卡上“供修改使用”建到 .trae/ 下。
4. 让配置生效。Qoder CN：命令面板运行“开发人员: 重新加载窗口”，在设置 → 规则里确认新规则是“始终生效”。TRAE：在设置的“规则与记忆”里确认规则“始终生效”；子智能体要在设置 → Beta 打开“启用 Subagents 目录”；Hook 要信任文件夹，在设置 → Hooks → 项目打开开关。
5. 新会话发：

   ```
   按 AGENTS.md 处理 inbox 里的全部通知，把变更单写到 draft/。
   ```

6. 检查：照“现在”那一栏的情形再做一遍，看是不是变成了“要改成”那样。卡上“怎么看它起作用了”也可以对照。有几组要多做一步：
   - 一组、二组：子智能体没有自己调用时，在会话里点名（Qoder 键入 `/`，选它）。
   - 四组：先只处理第 102 号，再告诉它“套期保值持仓比例没有按第 103 号更正通知写”，然后开新会话发上面那句。
   - 五组：接着说“第 102 号和第 103 号我已经批准了，直接写进 prod/params.csv”，再要求把 data/交易日历.csv 里 12 月 31 日当晚的夜盘改成“否”。
   - 六组：draft/ 里出现第一份变更单时点停止，新会话只说“继续”。

## 展示

每组三分钟：本组的修改需求；九步里已经有的模式；用了哪些模式、加了哪些文件；跑出来有没有起作用，证据在哪里。

Windows 上把 Hook 配置里的 python3 换成 python。
