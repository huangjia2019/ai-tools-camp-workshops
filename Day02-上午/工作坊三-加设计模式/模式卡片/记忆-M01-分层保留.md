# M01 分层保留

坐标：记忆 × 层级　　落地形式：规则

## 是什么

按作用域和用途把记忆分层，写清什么能进来、什么可以升级、什么过期删除。

## 放在哪一步

全程：哪些信息长期有效，哪些只在这一次有用。

## 供修改使用

交给 TRAE：“按这张卡，在项目里创建下面的文件，内容照抄，再按我们组的情况改。”

`.trae/rules/memory.md`

```markdown
# 记忆分三层

- 组织级：knowledge/规则摘录.md。只读，不改；要改先问我。
- 项目级：notes/project.md。这个仓库的约定，例如变更单格式、文件命名。
- 这一次：notes/session.md。本次任务的中间结果，任务结束后清空。
这一次里验证过、以后还要用的结论，先问我，同意后再写进 notes/project.md。
通知失效后，删掉 notes/ 里引用它的条目。
```

## 怎么看它起作用了

处理完一份通知后打开 notes/：session.md 里有中间结果，project.md 里只有你同意写入的条目。

## 代价

一次性的小任务用不上；只写不删，失效的内容会一直影响回答。
