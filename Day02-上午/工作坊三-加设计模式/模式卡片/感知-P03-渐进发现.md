# P03 渐进发现

坐标：感知 × 循环　　落地形式：规则

## 是什么

面对不熟悉的信息空间，先广扫、再精读、再深追，一轮轮缩小范围。

## 放在哪一步

第 3 步查依据：不知道规则写在哪一条时。

## 供修改使用

交给 TRAE：“按这张卡，在项目里创建下面的文件，内容照抄，再按我们组的情况改。”

`.trae/rules/search.md`

```markdown
# 找依据

找某条规则或某个参数的出处时，按轮缩小范围：
第一轮：列出 inbox/、knowledge/ 的文件名，按关键词搜索，记下命中的文件。
第二轮：只打开命中最多的两个文件，找到相关段落。
第三轮：顺着段落里提到的通知编号或条款再查一次。
最多三轮。每轮写一句“缩小到了哪里”；三轮还没找到，写“未找到”，不要猜。
```

## 怎么看它起作用了

问“套期保值持仓的新比例以哪份通知为准”，看回答里是否有逐轮缩小的记录，并在三轮内给出结论。

## 代价

已经知道文件在哪时直接打开；不设轮数上限，会一直搜下去。
