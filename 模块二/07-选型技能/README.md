# 07 选型技能（选讲）：安装、调用工具选型技能

用 Qoder CN 或 TRAE 打开本文件夹（菜单“文件 → 打开文件夹”），只打开这一个文件夹。

| 文件 | 内容 |
| --- | --- |
| [推荐器.py](推荐器.py) | 选型推荐器：`python 推荐器.py`（Mac 上用 python3） |
| [选型对照表.md](tool-selection/reference/选型对照表.md) | 放进技能的 reference/ |

## 提示词

```
帮我在 .trae/skills 下创建一个技能，名字叫 tool-selection（AI 编程工具选型）。
附件《选型对照表》放进这个技能的 reference/ 目录。技能要做到：
1. 先问清四个问题：部署要求、谁先用、先做哪类任务、管控要求；缺哪个问哪个；
2. 按这个顺序判断：先排除在国内用不了的；部署是硬条件；管控决定版本；谁用、做什么决定入口和用法；
3. 每条结论后面引对照表原话，写明是哪一栏；表里没写的，列进“要问厂商”；
4. 两家条件相同就并列推荐。
先给我看 SKILL.md 草稿，我确认后再写文件。
```

这段提示词按 TRAE 写。Qoder CN 用智能体模式，把第一句的 `.trae/skills` 换成 `.qoder/skills`。草稿确认后，智能体写出的 SKILL.md 在编辑区显示“拒绝 / 采纳”，点采纳。调用时输入 `/tool-selection`；不点名、只问“选哪个好”时，Qoder 也会自己调用这个技能，并用选择题把四个问题逐个问清。

## 测试用的六句话

1. 结算系统组：代码和数据不能出机房，先给研发用来改代码、补测试，要能限制命令并留审计日志。
2. 交易系统组：可以用公有云，研发要做一批长任务式的批量改动，安全部要求限制命令和 MCP。
3. 运维组：可以上云但要专线，先在流水线里跑批处理脚本，单点登录就够。
4. 业务部门：可以用公有云，先做日报和周会汇报，单点登录就够。
5. 新来的团队：可以用公有云，先读懂一个老仓库、补文档，一般管控。
6. 我们部门想上一个 AI 编程工具，选哪个好？
