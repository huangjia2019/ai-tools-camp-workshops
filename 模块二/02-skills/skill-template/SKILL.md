# 参数变更复核

## 输入
用户提供的通知（notice*.md）和当前参数 data.json。

## 步骤
1. 从通知中摘出：通知编号、合约范围、参数名称、新值、生效日期。
2. 缺任何一项就停下，列出待确认项，不修改任何文件，不补造。
3. 从 data.json 读出旧值，核对新旧值。只使用通知里明确写出的规则。
4. 按 templates/change-sheet.md 的格式，在回复里输出变更单。
5. 写明本次没有修改数据和代码；不把用户的确认写成已经发生的审批。

## 失败时
通知缺生效日期、合约范围写得含糊、两份材料互相冲突：停下，列出问题，等人确认。
