# 工作坊三：给智能体加上设计模式

## 背景

`模板/` 是一个处理交易所参数类通知的智能体（练习版）。用 TRAE 打开这个文件夹，它就按 `AGENTS.md` 工作，一份通知分九步处理：

| 步 | 做什么 | 说明 |
| --- | --- | --- |
| 1 | 读通知 | 读 inbox/ 里的新通知 |
| 2 | 分类 | 参数调整、节假日安排、更正 |
| 3 | 查依据 | 规则摘录、历史通知、交易日历 |
| 4 | 计算 | 用 scripts/calc.py 算涨跌停价和保证金 |
| 5 | 起草变更单 | 写到 draft/ |
| 6 | 跑测试 | 运行 tests/ 里的测试 |
| 7 | 提交审批 | 列出原值、新值、依据，等人确认 |
| 8 | 写入 | 先写 sim/，批准后写 prod/ |
| 9 | 记录 | 在 logs/ 记一笔 |

基础版只有 `AGENTS.md` 一份说明，没有用任何设计模式：先读哪些材料、数字用不用脚本算、什么时候停下来等人确认，都由模型自己判断。

## 任务

给这个智能体加上设计模式，让九步做得更稳。[模式卡片](模式卡片/README.md) 里有 27 个矩阵模式和可观测性，各一张卡，写明放在哪一步、可以照抄的片段、怎么验证、代价。

1. 至少覆盖三组、六个模式
2. 每个模式落成一个文件或一段规则，写在 模板/ 里
3. 设计卡逐条写：放在哪一步、为什么、代价、怎么验证
4. 同一件事再跑一遍，留下模式起作用的证据
5. 卡片上的片段可以照抄，按本组情况删改

## 节奏

| 时长 | 做什么 |
| --- | --- |
| 5 分钟 | 读任务：读本页和 模板/AGENTS.md，让 TRAE 按基础版处理一遍通知，看哪里不放心 |
| 8 分钟 | 选模式：从 模式卡片/ 选至少三组、六个，填进设计卡 |
| 17 分钟 | 写进文件：把卡上的片段交给 TRAE，按本组情况改好 |
| 7 分钟 | 跑一遍留证据：开新任务把同一件事再做一次，截图或复制对话片段 |
| 3 分钟 | 准备展示：按 展示.md 定好谁讲、讲哪三件事 |
| 15 分钟 | 展示与讲评：四组各 3 分钟，讲师讲评 |

## 怎么开始

1. 把 `模板/` 复制到自己的练习目录，用 TRAE 打开，信任作者。
2. 先不加任何模式，对 TRAE 说：“按 AGENTS.md 处理 inbox 里的全部通知，把变更单写到 draft/。”看它读了哪些文件、数字怎么算、有没有停下来确认。
3. 打开 [模式卡片/README.md](模式卡片/README.md)，至少选三组、六个模式，填进 [设计卡.md](设计卡.md)。
4. 把卡上的片段交给 TRAE，例如：“按 模式卡片/治理-G01-审批门.md，在项目里创建对应的文件，内容照抄。”再按本组情况改。
5. 开一个新任务，把第 2 步那句话再说一次，对照前后的差别，截图或复制对话片段。
6. 按 [展示.md](展示.md) 准备三分钟。

## 交什么

- 填好的 `设计卡.md`
- `模板/` 里新增或改过的文件
- 至少两份证据（截图或对话片段），写明是哪个模式起的作用

## 注意

- 材料都是练习数据，虚构，不代表任何交易所的规定。通知和数据之间可能有对不上的地方，发现了就记下来，不要直接改数据。
- 只用这里的材料，不要把公司代码、账号和业务数据放进 AI 工具。
- 规则写在 `.trae/rules/` 下的 md 文件里；不确定有没有被加载，可以追加到 `AGENTS.md`。
- 技能和子智能体在新任务里才稳定生效；子智能体要点名调用。
- Hook 要先信任文件夹，再到设置 > Hooks > 项目里打开开关。几个模式都用到 `.trae/hooks.json` 时，把各自的条目合并到同一个 `PreToolUse` 数组里。
- Windows 上把命令里的 python3 改成 python。
