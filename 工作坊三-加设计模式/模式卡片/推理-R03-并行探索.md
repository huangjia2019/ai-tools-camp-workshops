# R03 并行探索

坐标：推理 × 并行　　落地形式：提示词

## 是什么

同一个问题交给几条相互隔离的推理分别回答，再按答错的代价选择汇总方式。

## 放在哪一步

第 3 步查依据：对一句条款的理解有分歧时。

## 照抄就能用

直接发给 TRAE，按本组情况改：

```
下面这句条款，请分三次理解，每次只看指定的材料，不参考另外两次的结论：
A. 只看条款原文；
B. 结合 knowledge/规则摘录.md；
C. 结合 knowledge/历史通知/ 和 cases/ 里的写法。
每次写出结论和依据。三次结论一致就采用；不一致，列出分歧，等我决定。
条款：第 103 号通知“第 102 号通知其余内容不变”。
问题：更正后的套期保值持仓比例从哪天起用？
```

## 怎么看它起作用了

看三次理解是否分开写、各有依据，最后是否明确写出“一致”或“不一致”。更独立的做法是开三个新任务各问一次，或换一个模型再问。

## 代价

能用规则或脚本直接算出的问题不用这样做；几种理解可能犯同一个错，一致也不等于对；用量是几倍。
