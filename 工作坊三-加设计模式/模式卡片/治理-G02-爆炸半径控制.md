# G02 爆炸半径控制

坐标：治理 × 层级　　落地形式：Hook

## 是什么

用不可突破的硬边界和可以收放的软边界，把错误限制在可承受、可发现、可恢复的范围。

## 放在哪一步

全程：只能写指定的几个目录。

## 照抄就能用

交给 TRAE：“按这张卡，在项目里创建下面的文件，内容照抄，再按我们组的情况改。”

`.trae/hooks.json`

```json
{
  "version": 1,
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "python3 .trae/hooks/scope.py",
            "timeout": 10
          }
        ]
      }
    ]
  }
}
```

`.trae/hooks/scope.py`

```python
import json, re, sys

# 工作坊里还要让 TRAE 写 .trae/ 下的文件；正式使用时把 ".trae/" 去掉
ALLOWED = ("draft/", "notes/", "logs/", "sim/", "prod/", "cases/", ".trae/")
tool_input = json.load(sys.stdin).get("tool_input", {})
paths = [v.replace("\\", "/") for v in tool_input.values()
         if isinstance(v, str) and "\n" not in v and re.search(r"\.(py|md|csv|json|jsonl)$", v)]
outside = [p for p in paths if not any(re.search(r"(^|/)" + re.escape(a), p) for a in ALLOWED)]

if outside:
    json.dump({"hookSpecificOutput": {
        "hookEventName": "PreToolUse",
        "permissionDecision": "deny",
        "permissionDecisionReason": "只能写 draft/、notes/、logs/、sim/、prod/、cases/：" + "、".join(outside)
    }}, sys.stdout, ensure_ascii=False)
sys.exit(0)
```

已经有 `.trae/hooks.json` 的，只把 `PreToolUse` 数组里的这一条加进去。Windows 上把 python3 改成 python。

## 怎么看它起作用了

让它修改 data/结算价.csv 或 scripts/calc.py，看是否被拦下；写 draft/ 不受影响。也可以在 TRAE 设置里打开沙箱。

## 代价

边界只写在提示词里，模型可能会忘；边界太紧，正常工作也做不了，大家就会关掉它。和自愈循环一起用时，要先决定 scripts/ 放不放开。
