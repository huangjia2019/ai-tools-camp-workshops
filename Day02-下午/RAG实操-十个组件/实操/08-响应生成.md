# 实操八　响应生成：会拒答，按问题挑句子，更正过的以更正为准

只改 `rag/generate.py`。

## 现象

```
python check.py 08 --看
```

基础版按字面重合挑一句照抄：问“明天会涨停吗”也照样作答；问“平今是什么意思”，挑中的是问句本身；更正过的比例照抄原通知的 9%，只引一份文件。

## 要做的事

1. 拒答：问行情走势（会不会涨停、跌停）和账户情况的，结论写“资料中没有依据，不能回答”，不写依据；问到的事项在交上来的块里一句都没提到（例如交割手续费），也拒答。
2. 按问题挑句子：问“多少”优先挑带数值和单位的句子；问“什么意思”挑定义句；问句（“问：”开头、问号结尾）不用。
3. 更正：结论所在的文件被更正过，更正通知讲到同一事项时，结论用更正通知那一句，依据同时引原通知和更正通知。
4. 回答格式不变：第一行“结论：”，后面每份文件一行“依据：〔编号〕原文”。

## 交给 TRAE 的提示词

用 TRAE 打开 RAG实操-十个组件 文件夹，把下面这段交给它；也可以自己改。

```
只改 rag/generate.py 里的 answer(req, hits)。问行情走势、账户情况的直接拒答；问题里的关键名词（手续费、交割、保证金这类）在块里一句都没出现时拒答；拒答时只写结论一行。挑结论句子时：问“多少”的优先带数值和单位的句子，问“什么意思”的优先“指……”的定义句，不用问句。结论所在文件的元数据有“被更正”、更正通知又讲到同一事项时，结论用更正通知的句子，依据同时引用两份文件。回答格式不变。改完运行 python check.py 08。
```

## 检查

```
python check.py 08
python eval.py --save 实操08
python eval.py --compare 基线 实操08
```

`check.py 08` 查这几项，逐项检查并记录未通过的原因：

- 问明天会不会涨停：拒答，不写依据
- 问交割手续费，资料里没有：拒答
- 更正过的比例：结论用 8%，依据同时引第102号和第103号
- 问收费标准：挑带数值的那一句（8000 元/月）
- 问什么意思：结论用答句，不用问句
