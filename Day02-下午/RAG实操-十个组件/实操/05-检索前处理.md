# 实操五　检索前处理：提取日期、传入访问权限，补全检索用语

只改 `rag/pre.py`。

## 现象

```
python check.py 05 --看
```

基础版把问题原样拿去检索：“从 1 月 4 日起”里的日期没人认，现行参数表和第102号一起参与检索；“平今多少钱一手”和文件里的“平今仓手续费”字面对不上。

## 要做的事

1. 用 utils.parse_date() 把问题里的日期换算出来，写进 as_of；没写日期就是今天。
2. 判断是不是在问过去：问题里有“国庆”“当时”“以前”这类词，或者问到的合约月份已经过去（utils.contract_month()），history 设为 True。
3. 写过滤条件 filters：role 由已认证的调用方传入，不能从提问文本推断。会员的权限是 ["公开"]，员工（role 为 staff）是 ["公开", "内部"]；不问过去时，再加上“有效于”: as_of。
4. 把口语说法扩展成文件里的说法，加到 query 后面：平今 → 平今仓手续费，套保 → 套期保值，多少钱 → 手续费 元/手。同义词从会员问答和通知原文里找。

## 交给 TRAE 的提示词

用 TRAE 打开 RAG实操-十个组件 文件夹，把下面这段交给它；也可以自己改。

```
只改 rag/pre.py。用 utils.parse_date 算出问题问的是哪一天（没写就是 today），写进 as_of；问题里有“国庆、当时、以前、原来”，或者问到的合约月份早于今天所在的月份时，history 为 True；filters 写成字典：权限会员是 ["公开"]、staff 是 ["公开", "内部"]，history 为 False 时再加“有效于”: as_of；再把“平今、套保、多少钱”这类口语扩展成文件里的说法，加到 query 后面。改完运行 python check.py 05。
```

## 检查

```
python check.py 05
python eval.py --save 实操05
python eval.py --compare 基线 实操05
```

`check.py 05` 查这几项，逐项检查并记录未通过的原因：

- “从 1 月 4 日起”：as_of 和过滤条件里的“有效于”都是 2027-01-04
- “现在”：按今天 2026-12-30 过滤
- 问国庆期间：history 为 True，不按日期过滤
- 会员只看公开文件；员工（staff）也能看内部文件
- 口语改写：“平今”扩展成文件里的“平今仓手续费”
