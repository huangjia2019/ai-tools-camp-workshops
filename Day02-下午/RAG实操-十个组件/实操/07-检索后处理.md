# 实操七　检索后处理：去掉被取代的旧文件，带上更正通知

只改 `rag/post.py`。

## 现象

```
python check.py 07 --看
```

基础版直接取相似度最高的 4 块：新旧两份手续费通知一起交给响应生成；会员问测试环境，内部运维手册也交了上去；第102号被第103号更正过，更正通知却没带上。

## 要做的事

1. 候选里新旧两份都在时，去掉被取代的那份：元数据“被取代”写着的那份新文件也在候选里，旧的就不用。
2. 会员提问时（role 不是 staff），去掉权限为“内部”的块。
3. 问题里有合约代码时，只讲别的合约的块不要（utils.contract_codes()）。
4. 某块的文件被更正过（元数据“被更正”），而更正通知不在结果里，用 store.chunks_of() 取出更正通知里最相关的一块，放在它后面。最后最多留 TOP_K 块。

## 交给 TRAE 的提示词

用 TRAE 打开 RAG实操-十个组件 文件夹，把下面这段交给它；也可以自己改。

```
只改 rag/post.py 里的 postprocess(hits, req, store)：去掉被取代、而取代它的新文件也在候选里的块；role 不是 staff 时去掉权限为“内部”的块；问题里有合约代码时，去掉只提到别的合约的块；结果里有文件被更正过、更正通知却不在时，用 store.chunks_of 取出更正通知里和问题最相关的一块插在它后面；最后最多保留 TOP_K 块。改完运行 python check.py 07。
```

## 检查

```
python check.py 07
python eval.py --save 实操07
python eval.py --compare 基线 实操07
```

`check.py 07` 查这几项，逐项检查并记录未通过的原因：

- 新旧两份都在候选里：去掉被取代的第88号，留下第95号
- 第102号被更正过：把第103号的块一起交给响应生成
- 运维手册：会员提问时去掉，员工提问时保留
- 问 XM2703：XM2703 那一块排第一
- 每次最多留 TOP_K 块
