# 实操十　复杂 RAG 范式：智能体式 RAG：查一次不够，就再查一次

只改 `rag/agent.py`。

## 现象

```
python check.py 10 --看
```

问“1 月 4 日起，XM2701 结算价 20000 元/吨，持有 2 手套保持仓，交易保证金是多少”，要四样东西：第102号的比例、更正它的第103号、第99号的交易单位、规则摘录里的计算公式。普通 RAG 只检索一次，拿到的是最相似的几块，基础版答“资料不全，不能计算：缺少交易单位”。

## 要做的事

1. 实现 rag/agent.py 里的 missing(question, pool, req)：看手里已有的块，返回还要做的事。循环、计算工具、停止条件都已经写好。
2. 沿关系取文件：某块的元数据写着“被更正: 第103号”，而第103号不在手里，返回 ("文件", "第103号", "第102号被第103号更正")。
3. 金额题（is_amount() 为真）：手里没有计算公式那句（同时含“交易保证金”和“=”），返回 ("检索", "交易保证金 = 结算价 × 交易单位 × 持仓手数 × 交易保证金比例", "算金额要计算公式")；没有交易单位那句（含“交易单位”和“吨/手”），返回 ("检索", "交易单位 吨/手", "算金额要交易单位")。
4. 资料齐了返回空列表，循环就停；最多查 MAX_ROUNDS 轮。

```
只改 rag/agent.py 里的 missing(question, pool, req)。规则一：pool 里某块的 meta 有“被更正”，而那份更正通知不在 pool 里，返回 ("文件", 更正通知编号, 原因)。规则二：is_amount(question) 为真时，pool 的句子里没有同时含“交易保证金”和“=”的，返回 ("检索", "交易保证金 = 结算价 × 交易单位 × 持仓手数 × 交易保证金比例", "算金额要计算公式")；没有同时含“交易单位”和“吨/手”的，返回 ("检索", "交易单位 吨/手", "算金额要交易单位")。资料齐了返回 []。不要改 run() 和 compute_amount()。改完运行 python agent.py "1 月 4 日起，XM2701 结算价 20000 元/吨，持有 2 手套保持仓，交易保证金是多少？"，再运行 python check.py 10。
```

## 检查

```
python check.py 10
python eval.py --save 实操10
python eval.py --compare 基线 实操10
```

`check.py 10` 查这几项，逐项检查并记录未通过的原因：

- 手里只有第102号：要去取更正它的第103号
- 金额题缺计算公式和交易单位：各检索一次
- 资料齐了就停；问夜盘这种一次就够的题，不再多查
- 跑一遍金额题：依据里有第102号、第103号、第99号和规则摘录
- 结论是 20000 × 5 × 2 × 8% = 16000 元
