# 工作坊三：选模式 · 谁来拍板

## 任务

为“参数变更智能体”出一张设计卡：流程分几步，每一步用哪个设计模式、为什么、代价是什么，哪几步必须停下来等人确认，这个智能体不做什么。

先交换信息，把成员提供的事实写下来，写清提供人；再请 TRAE 出一版初稿，比较它增加了哪些步骤、漏了哪些条件。TRAE 三分钟没返回，就在模板上接着人工写。
